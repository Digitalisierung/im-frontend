# Angular Frontend – Dynamischer Produktkatalog mit anpassbarem Formular
## Ziel
Entwickeln Sie in Angular eine Frontend-Anwendung, die als Teil einer verteilten Web-Anwendung dient. Das System soll Produkte und Produktkataloge verwalten können. Dabei ist besonders wichtig, dass Produkte unterschiedliche Eigenschaften haben können und das Produktformular dynamisch anpassbar ist.

## Anforderungen
### Funktionalität

1. Produkte
   - Neues Produkt anlegen
     - Formular dynamisch um Felder erweiterbar (z. B. Farbe, Größe, Hersteller).
   - Produkt bearbeiten
     - Eigenschaften wie Name oder zusätzliche Felder ändern.
   - Alle Produkte auflisten (Übersicht).
   - Produktdetails anzeigen.
   - Produkt löschen.
2. Produktkataloge
   - Neuen Produktkatalog / neue Kategorie erstellen.
   - Produktkatalog löschen.
   - Produkte einem Katalog zuweisen oder daraus entfernen.
   - Alle Produktkataloge anzeigen mit Anzahl enthaltener Produkte.

### Formular
Das Formular für neue Produkte ist dynamisch:
- Benutzer kann zusätzliche Felder hinzufügen oder entfernen.

### REST-Schnittstelle
- Formulardaten sollen in DTOs gespeichert werden.
  - Kommunikation über REST-Services.
- API-Basisadresse:
```text
http://localhost:8080
```

## Aufgabenstellung
- Erstellen Sie ein neues Angular-Projekt in Replit
- Implementieren Sie eine Produkt-Komponente mit CRUD-Funktionalität (Create, Read, Update, Delete).
- Implementieren Sie eine Katalog-Komponente, die Produkte gruppieren kann.
- Erstellen Sie ein dynamisches Produktformular:
  - Felder hinzufügen/entfernen per Klick.
  - Daten an das Backend (http://localhost:8080)
- Fügen Sie eine Übersicht hinzu, die alle Kataloge inkl. Produktanzahl darstellt.

> Hinweise für Replit:
> - Verwende Angular Reactive Forms für das dynamische Formular.
> - Strukturiere das Projekt mit Services für die REST-Kommunikation.
> - Nutze ggf. Angular Material für UI-Komponenten.
